GEPPETTO CERTIFICATE GENERATOR - GITHUB PAGES

Upload these four files directly to the ROOT of your GitHub repository:
- index.html
- style.css
- script.js
- certificado.png

Do not upload only the ZIP and do not place the files inside another folder.

After uploading, click "Commit changes". Then open:
Settings > Pages > Deploy from a branch > main > /(root) > Save.

The public URL will normally be:
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/

The participant's name is processed only in their own browser. It is not sent to a server or saved by this page.
